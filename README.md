# Реквием — тёмный плеер

Офлайн-плеер для своей музыки, PWA. Треки хранятся только на устройстве (IndexedDB).
Стиль — из той же семьи, что «Ноктюрн»: монохром, плёночное зерно, готика, тёмно-красный акцент.

## Запуск на компьютере

```bash
npm install        # один раз
npm run dev        # режим разработки: http://localhost:5173
npm test           # тесты очереди и разбора имён файлов
npm run build      # сборка в папку dist/
npm run preview    # посмотреть собранную версию: http://localhost:4173
npm run icons      # пересобрать иконки (терновое сердце)
```

Service worker (офлайн) включается только в собранной версии.

## Что умеет

- Добавлять файлы или целую папку: mp3, m4a, flac, ogg, opus, wav. Теги и обложки читаются сами
  (music-metadata), без тегов — название и артист берутся из имени файла «Артист - Название».
- Трекам без обложки рисуется своя, «тушью»: лезвия, кресты, готическая буквица, зерно.
- Треки, альбомы, «любимое», поиск, сортировка, очередь, «играть следующим», перемешивание, повтор.
- Музыка играет в фоне и при выключенном экране; на экране блокировки — обложка, название и кнопки
  (Media Session). Вид самой плашки рисует Android — его поменять нельзя.
- Помнит очередь и место в треке между запусками.
- Настройка «Чёрно-белые обложки» — обесцвечивает их и в плеере, и на экране блокировки.

## Опубликовано

**https://xqwxqxqwx.github.io/requiem/** — GitHub Pages, ветка `gh-pages`.

Обновить сайт после изменений в коде: `npm run deploy` — прогонит тесты, соберёт проект
и опубликует `dist` в ветку `gh-pages`. Сайт обновится примерно через минуту.
Код храни в ветке `main` как обычно (`git commit` + `git push`).

## На телефоне

PWA (установка, офлайн) требует **HTTPS** — например, GitHub Pages, как у «Ноктюрна».
Пути в сборке относительные (`base: './'`), поэтому плеер работает и в подпапке.

**Android (Chrome):** меню ⋮ → «Установить приложение».

Если музыка в фоне обрывается (Xiaomi, Huawei, Samsung) — сними для Chrome ограничения батареи.
